# Security policy

## Reporting a vulnerability

Report it privately through GitHub: open the **Security** tab of this repository and
choose **Report a vulnerability**. The report reaches the maintainer alone and stays
private until a fix is out.

For anything that is not a vulnerability, open an
[issue](https://github.com/alxmax/excalidraw-diagram/issues).

## What this plugin does, for scoping a report

It runs a local Python process, makes no network call of its own and collects no data.
`plugin/README.md` lists what it runs, writes and fetches, and its Privacy section says
what leaves the machine, which is nothing.
